이곳은 게임 개발 프로젝트와 학습 기록을 모으는 개인 공간입니다. 완성된 결과물과 함께, 그것을 만드는 과정에서 생긴 질문과 해결 방법도 남기려고 합니다.

## 직접 만들며 이해하기

관심의 중심에는 C++, DirectX 12, 그리고 렌더링이 있습니다. 화면에 결과를 그리는 것에서 더 나아가, 그래픽스 시스템이 어떻게 동작하는지 이해하는 것을 지향합니다.

프로젝트 공간에는 DX12 미니 엔진, Nightmare Lab, 셰이더 실험, Unity 프로젝트를 정리합니다. 실행 화면과 구체적인 구현 기록은 자료를 준비하면서 차례로 보완할 예정입니다.

## 이 공간에 남길 것들

- **Projects** — 프로젝트의 목적, 핵심 구현과 문제 해결 과정
- **Notes** — 개발하면서 배운 내용과 다시 찾아볼 기록
- **Lab** — 작은 그래픽스 실험, 웹 게임과 개발 도구

## 다른 곳의 기록도 함께

기존 개발 글은 [Velog](https://velog.io/@rniman/posts)에, 공개 코드는 [GitHub](https://github.com/rniman)에 이어집니다. 이 사이트는 각 공간을 연결하고 작업의 맥락을 소개하는 출발점입니다.
